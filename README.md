
# Proyecto Docente Plaza UAM2026-1055TU 

**English version below**

Este repositorio contiene el proyecto docente elaborado para la plaza de **Profesor Titular de Universidad** del área de conocimiento **Bioquímica y Biología Molecular** en la **Universidad Autónoma de Madrid**.

El documento ha sido elaborado mediante [Quarto](https://quarto.org/) y LaTeX. Se comparten tanto los archivos fuente como el [PDF final](_book/PROYECTO-DOCENTE.pdf), con licencia *Creative Commons* [BY-NC-SA](license.md).

## Descripción

El objetivo de este repositorio es facilitar el acceso abierto, transparente y reproducible al proyecto docente presentado en el contexto del proceso selectivo correspondiente a la plaza **UAM2026-1055TU**.

La publicación de los archivos fuente tiene como finalidad facilitar la trazabilidad del documento, permitir su compilación independiente y favorecer buenas prácticas de documentación académica. El repositorio incluye los materiales necesarios para consultar, compilar y reutilizar, bajo los términos de la licencia indicada, el documento final del proyecto docente.

# Teaching Statement for Position UAM2026-1055TU

This repository contains the teaching statement prepared for the position of **Associate Professor / Profesor Titular de Universidad** in the area of **Biochemistry and Molecular Biology** at the **Universidad Autónoma de Madrid**.

The document has been prepared using [Quarto](https://quarto.org/) and LaTeX. Both the source files and the [final PDF](_book/PROYECTO-DOCENTE.pdf) are shared under a _Creative Commons_ BY-NC-SA license.

## Description

The aim of this repository is to provide open, transparent and reproducible access to the teaching statement submitted as part of the selection process for position **UAM2026-1055TU**.

The source files are shared to ensure transparency, traceability and independent compilation of the document, following good practices in academic documentation. The repository includes the necessary materials to consult, compile and reuse, under the terms of the indicated license, the final version of the teaching statement.
